## User Stories

- **REQ-001 (Менеджер):** Как менеджер я хочу создавать динамические правила рекомендаций, чтобы управлять продуктовыми предложениями.
- **REQ-002 (Менеджер):** Как менеджер я хочу видеть статистику по применению правил, чтобы понимать, какие рекомендации наиболее эффективны.
- **REQ-003 (Менеджер):** Как менеджер я хочу получать статистику в виде списка правил с количеством применений, отсортированного по убыванию.
- **REQ-004 (Пользователь):** Как пользователь я хочу получать список рекомендаций, учитывающих как динамические, так и статические правила, даже если база данных временно недоступна.

## Нефункциональные требования (NFR)

- **NFR-001:** Производительность: API выдачи рекомендаций должно отвечать не более чем за 500 мс при средней нагрузке.
- **NFR-002:** Логирование: все ключевые операции (выдача рекомендаций, ошибки БД, создание правил) должны логироваться на уровне DEBUG/WARN.
- **NFR-003:** Отказоустойчивость: при недоступности базы данных сервис должен продолжать работать, используя статические правила.
